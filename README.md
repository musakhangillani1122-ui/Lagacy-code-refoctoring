
# Student Management System

## Project Introduction
This is a simple Python-based Student Management System.
It allows users to add, display, and search student records.

## Task 1: Identified Legacy Code Issues
1. Poor variable names.
2. Unnecessary duplicate lists.
3. Missing error handling.
4. Poor code structure.
5. Missing documentation.
6. Difficult maintenance.

## Task 2: Refactoring Improvements
1. Replaced unclear variable names with meaningful names.
2. Used one list of dictionaries to store student records.
3. Divided the program into separate functions.
4. Added try-except for error handling.
5. Added checks for empty student records.
6. Improved student searching.

## Task 3: Documentation
Added comments and function documentation
to explain the program.
